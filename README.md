# AAISSC Seminar Website

A modern, single-page React application built for the **Two-Day National Seminar on Applications of Artificial Intelligence in Sustainable and Smart Computing (AAISSC)**.

## About the Seminar

Artificial Intelligence (AI) has been recognized as one of the most groundbreaking technologies of the 21st century. With the emergence of data-driven technologies, the need for sustainable and smart computing solutions has become more urgent than ever before. 

This seminar aims to provide a common platform for academicians, researchers, industry professionals, and students to present the latest developments, applications, and future trends of AI-based sustainable computing systems. It is hosted at **Midnapore City College**, West Bengal, and is technically sponsored by the **IEEE Computer Society Kolkata Section Chapter**.

This website serves as the central hub for the event, showcasing the seminar's objectives, esteemed resource persons, call for papers, and registration details. The site features a highly dynamic, premium interface with glassmorphism elements, interactive bento-box layouts, and custom 3D hover animations to reflect the futuristic "Artificial Intelligence" theme.
